# Riverside Dental Care — Landing Pages

Two landing pages for the **same** fictional company, *Riverside Dental Care*,
built as a before/after contrast in web design eras.

| Folder | Style | Open |
|--------|-------|------|
| [`2000s/`](./2000s/index.html) | Authentic early-2000s web: table layout, `<marquee>`, `<blink>`, visitor counter, "best viewed in Netscape", Comic Sans, under-construction GIFs. | `2000s/index.html` |
| [`premium/`](./premium/index.html) | Modern high-end UI: editorial serif/sans pairing, dark emerald + gold palette, sticky glass nav, scroll-reveal animations, fully responsive. | `premium/index.html` |

Both are self-contained single HTML files — just open them in a browser.
The 2000s page references period image assets (`.gif`/`.jpg`) by name to keep
the markup authentic; they render as broken-image placeholders, exactly as an
unmaintained old site would.
